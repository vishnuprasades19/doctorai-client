# DoctorAI

DoctorAI is an AI-powered health information assistant. It provides general health information and is not a substitute for professional medical advice.

## Production

- Client: https://doctorai-client-coral.vercel.app/
- API: https://doctorai-server.onrender.com/

## Local development

Install dependencies and start the client:

```bash
npm install
npm run dev
```
